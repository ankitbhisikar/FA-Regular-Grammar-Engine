## 🚀 Overview

In the Chomsky hierarchy, **Regular Languages** (Type-3) can be recognized by Finite Automata (DFA/NFA) and generated by **Regular Grammars** (either Right-Linear or Left-Linear).

This engine bridges the gap between state machines and grammar productions by:
1. Allowing complete customization of a DFA (states, alphabet, transition table, start and accepting states).
2. Synthesizing formal 4-tuple grammar definitions: $G = (V, \Sigma, R, S)$.
3. Rendering vector-based **SVG transition diagrams** in real time.
4. Simulating input strings through the automaton, outputting an **acceptance verdict** and **step-by-step derivation traces** for both $G_R$ and $G_L$.

## 📖 Theoretical Background

### 1. Finite Automaton (DFA) Definition
A Deterministic Finite Automaton is formally defined as a 5-tuple:
$$M = (Q, \Sigma, \delta, q_0, F)$$
Where:
- $Q$ is a finite set of states $\{q_0, q_1, \dots, q_{n-1}\}$.
- $\Sigma$ is a finite set of input symbols (the alphabet).
- $\delta: Q \times \Sigma \to Q$ is the transition function.
- $q_0 \in Q$ is the initial/start state.
- $F \subseteq Q$ is the set of final (accepting) states.

---

### 2. Conversion to Right-Linear Grammar ($G_R$)
A Right-Linear Grammar produces strings by expanding non-terminals on the right side:
$$G_R = (V, \Sigma, P_R, S_R)$$

**Construction Rules:**
1. **Variables / Non-terminals ($V$)**: Each state in $Q$ corresponds to a non-terminal symbol ($V = Q$).
2. **Start Symbol ($S_R$)**: The DFA's start state ($S_R = q_0$).
3. **Transition Productions**: For every transition $\delta(q_i, a) = q_j$:
   $$q_i \to a \, q_j$$
4. **Acceptance / Termination Productions**: For every accepting state $q_f \in F$:
   $$q_f \to \varepsilon$$

**Derivation Method:**
For a string $w = a_1 a_2 \dots a_k$ accepted by path $q_0 \to q_1 \to \dots \to q_k$ where $q_k \in F$:
$$q_0 \Rightarrow a_1 q_1 \Rightarrow a_1 a_2 q_2 \Rightarrow \dots \Rightarrow a_1 a_2 \dots a_k q_k \Rightarrow a_1 a_2 \dots a_k (\varepsilon) = w$$

---

### 3. Conversion to Left-Linear Grammar ($G_L$)
A Left-Linear Grammar produces strings by expanding non-terminals on the left side:
$$G_L = (V', \Sigma, P_L, S)$$

**Construction Rules:**
1. **Variables ($V'$)**: $V' = Q \cup \{S\}$ where $S$ is a new start symbol.
2. **Start Symbol**: $S$.
3. **Transition Productions**: For every transition $\delta(q_i, a) = q_j$:
   $$q_j \to q_i \, a$$
4. **Base / Initial Production**: For the DFA start state $q_0$:
   $$q_0 \to \varepsilon$$
5. **Acceptance Link Productions**: For every accepting state $q_f \in F$:
   $$S \to q_f$$

**Derivation Method:**
The derivation begins from the goal non-terminal $S$, substitutes the final state $q_k$, and unwinds backward to $q_0$:
$$S \Rightarrow q_k \Rightarrow q_{k-1} a_k \Rightarrow q_{k-2} a_{k-1} a_k \Rightarrow \dots \Rightarrow q_0 a_1 \dots a_k \Rightarrow (\varepsilon) a_1 \dots a_k = w$$

## 🛠️ User Guide

1. **Step 01 — Configuration**:
   - Enter the desired number of states in **States (n)** (e.g., `3`).
   - Enter the alphabet in **Alphabet (Σ)** separated by commas (e.g., `0,1` or `a,b`).
   - Click **Rebuild Table** to update the transition matrix.

2. **Step 02 — Transition Function ($\delta$)**:
   - Select destination states from dropdowns for each state-symbol pair.
   - Click the **start** chip under a state to set the initial state (marked in amber).
   - Click the **final** chip under states to toggle accepting status (marked in teal).
   - Click **Generate Grammars →**.

3. **Step 03 — State Diagram**:
   - View the generated SVG state machine diagram. Amber rings indicate the start state; double teal rings indicate accepting states.

4. **Step 04 — Derived Grammars**:
   - Review the formal definitions:
     - **$G_R$** (Right-Linear Grammar): Rules of the form $A \to aB \mid \varepsilon$.
     - **$G_L$** (Left-Linear Grammar): Rules of the form $A \to Ba \mid \varepsilon$.

5. **Step 05 — Test & Derivation Trace**:
   - Enter an input string into the text field (e.g., `1001`, `01`).
   - Click **Run** or press <kbd>Enter</kbd>.
   - View the **Accepted / Rejected verdict**, transition path, and detailed step-by-step derivations in both grammars.

6. **Step 06 — History**:
   - Click the **📜 History** button in the header to open the history drawer.
   - View past DFA configurations, test strings, timestamps, and verdicts.
   - Click **Restore** on any entry to reload that DFA configuration instantly.
   - Use **Export SQL** to download a complete `.sql` dump of the history database.

## 🧪 Example Automata & Test Cases

### Example 1: Strings Ending in `01` (Default Preset)
- **Alphabet**: $\Sigma = \{0, 1\}$
- **States**: $Q = \{q_0, q_1, q_2\}$
- **Start State**: $q_0$
- **Final States**: $F = \{q_2\}$
- **Transitions**:
  - $\delta(q_0, 0) = q_1$, $\delta(q_0, 1) = q_0$
  - $\delta(q_1, 0) = q_1$, $\delta(q_1, 1) = q_2$
  - $\delta(q_2, 0) = q_1$, $\delta(q_2, 1) = q_0$

**Test Strings**:
| String | Expected Result | Path |
| :--- | :--- | :--- |
| `01` | **Accepted** | $q_0 \to q_1 \to q_2$ |
| `1101` | **Accepted** | $q_0 \to q_0 \to q_0 \to q_1 \to q_2$ |
| `010` | **Rejected** (ends in $q_1 \notin F$) | $q_0 \to q_1 \to q_2 \to q_1$ |
| `111` | **Rejected** (ends in $q_0 \notin F$) | $q_0 \to q_0 \to q_0 \to q_0$ |

---

### Example 2: Strings Containing Even Number of `0`s
- **Alphabet**: $\Sigma = \{0, 1\}$
- **States**: $Q = \{q_0, q_1\}$ ($q_0$ = even `0`s, $q_1$ = odd `0`s)
- **Start State**: $q_0$
- **Final States**: $F = \{q_0\}$
- **Transitions**:
  - $\delta(q_0, 0) = q_1$, $\delta(q_0, 1) = q_0$
  - $\delta(q_1, 0) = q_0$, $\delta(q_1, 1) = q_1$

**Test Strings**:
- `00`: **Accepted** ($q_0 \to q_1 \to q_0$)
- `10101`: **Accepted** ($q_0 \to q_0 \to q_1 \to q_1 \to q_0 \to q_0$)
- `000`: **Rejected** ($q_0 \to q_1 \to q_0 \to q_1$)

---

### Example 3: Strings Containing Substring "101"
- **Alphabet**: $\Sigma = \{0, 1\}$
- **States**: $Q = \{q_0, q_1, q_2, q_3\}$ ($q_3$ = pattern matched)
- **Start State**: $q_0$
- **Final States**: $F = \{q_3\}$

**Test Strings**:
- `101`: **Accepted** ($q_0 \to q_1 \to q_2 \to q_3$)
- `001010`: **Accepted**
- `1100`: **Rejected**

---

### Example 4: Binary Numbers Divisible by 3
- **Alphabet**: $\Sigma = \{0, 1\}$
- **States**: $Q = \{q_0, q_1, q_2\}$ (where $q_i$ represents remainder $i \pmod 3$)
- **Start State**: $q_0$, **Final States**: $F = \{q_0\}$

**Test Strings**:
- `11` ($3_{10}$): **Accepted**
- `110` ($6_{10}$): **Accepted**
- `1001` ($9_{10}$): **Accepted**
- `100` ($4_{10}$): **Rejected** (ends in $q_1$)

---

### Example 5: Alternating 0s and 1s
- **Alphabet**: $\Sigma = \{0, 1\}$
- **States**: $Q = \{q_0, q_1, q_2, q_3\}$ ($q_3$ = trap state)
- **Start State**: $q_0$, **Final States**: $F = \{q_0, q_1, q_2\}$

**Test Strings**:
- `0101`: **Accepted**
- `101`: **Accepted**
- `001`: **Rejected** (reaches trap state $q_3$)
